# EduVerse 3D AI Academy — Simple 3D Demo

This is a simple single-file website with real interactive 3D scenes.

## How to use
1. Download and unzip the file.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. Use the buttons to switch between Chemistry, Physics, Biology and Mathematics.
4. Drag the 3D scene to rotate it. Scroll to zoom.

## 3D scenes included
- Chemistry: Water molecule
- Physics: Simple electric circuit
- Biology: DNA double helix
- Mathematics: 3D coordinate system and vector

## Important
This demo loads Three.js from a public CDN, so it needs an internet connection the first time it opens. It is a visual demonstration, not a complete scientific simulation.
